# Envia un missatge a al grup de Telegram de la `Comunitat en català d'OpenStreetMap`

Envia un missatge a al grup de Telegram de la
`Comunitat en català d'OpenStreetMap`

## Usage

``` r
missatge_telegram(
  missatge = "Hi ha canvis a [monitormequi](https://yopaseopor.github.io/monitormequi).",
  parse_mode = "Markdown"
)
```

## Arguments

- missatge:

  Text del missatge.

- parse_mode:

  El missatge s'interpreta com a `Markdown` o `HTML`.
