# Mostra les versions que introdueixen canvis en html

Funció pensada per usar en fitxers `.qmd` o `.Rmd`.

## Usage

``` r
versio_canvis_html(x)
```

## Arguments

- x:

  Una llista de canvis retornada per
  [`cerca_versio_canvis()`](https://yopaseopor.github.io/monitormequi/docs/reference/cerca_versio_canvis.md).

## Value

Mostra les taules html amb informació del conjunt de canvis que ha
modificat etiquetes.
